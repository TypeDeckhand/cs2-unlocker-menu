## 🧩 About

**Counter-Strike 2 Companion** is a curated list of Counter-Strike 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, radar viewer, HUD customizer
- **Quality-of-Life Helpers** — config manager, crosshair editor, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Practice Config — load practice settings for offline study
- Show Hitboxes — visualize hitboxes in practice mode
- Demo Playback — review recorded matches with speed control
- Bot Difficulty — adjust bot behavior for training

### Wallhack
- Custom HUD — rearrange HUD elements for better readability
- Radar Overlay — enlarged radar for map awareness
- Crosshair Editor — fine-tune crosshair style and color
- Colorblind Modes — alternative color schemes for visibility

### Aimbot
- Config Manager — save and switch between configs
- Launch Options — preset launch parameters for performance
- Net Graph — toggle network statistics display
- Buy Bind Helper — create buy binds for practice
